# Heroes of Might and Craft III

> 🚧 **Work in progress.** This mod is in early development and a lot will change.

A Minecraft Forge mod inspired by Heroes of Might and Magic III.

## Info

| | |
|---|---|
| **Minecraft** | 1.20.1 |
| **Mod loader** | Forge 47.4.28 |
| **Java** | 17 |
| **Mod ID** | `hocm3` |

## Running the project

Requirements: **JDK 17** and an IDE (IntelliJ IDEA recommended).

1. Clone the repository:
   ```
   git clone https://github.com/your-username/Heroes-of-Craft-and-Magic-3.git
   ```
2. Open the folder in IntelliJ and import `build.gradle`.
3. Run `gradlew genIntellijRuns`.
4. Launch the game with the `runClient` task.

## Status

Hobby and learning project with no planned release date. Bugs and crashes are expected.
